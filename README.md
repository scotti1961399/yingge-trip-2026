# 11/28 鶯歌小旅行｜手機分頁互動版

本網站只有一個 `index.html`，不需安裝框架、資料庫或依賴套件。

## 發布到 GitHub Pages
1. 新增 GitHub Repository（可選 Public）。
2. 將 `index.html` 上傳到 Repository 根目錄並 Commit。
3. 到 Settings → Pages，選擇 Deploy from a branch，Branch 選 main、資料夾 /(root)。
4. 等 GitHub Pages 建立 HTTPS 網址後，在手機 Safari/Chrome 開啟該網址，互動操作才會像正式網站。

如直接在 ChatGPT 附件、圖片預覽器或部分手機檔案檢視器中開啟，JavaScript 可能遭到限制，並不等於網站本身壞掉。

本版保留原行程內容，將行程／吃喝／晚上／交通改為分頁，店家與備案採點開展開，14:40 陶藝報到提醒為主。
